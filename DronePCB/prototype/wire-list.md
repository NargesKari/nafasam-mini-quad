# Perfboard point-to-point connections

Module pin identifiers below are **printed header labels**, not physical pin numbers. Q1-Q4 use the actual AO3400A pin numbers. All points on the same line connect together.

- **3V3**: U1.3V3, U2.VIN, R9.1, R10.1, C14.1, C15.1
- **5V**: U1.5V, U3.VOUT, C11.1, C12.1
- **GATE1**: Q1.1, R1.2, R5.1
- **GATE2**: Q2.1, R2.2, R6.1
- **GATE3**: Q3.1, R3.2, R7.1
- **GATE4**: Q4.1, R4.2, R8.1
- **GND**: U1.GND, U2.GND, U2.AD0, U3.GND, J1.2, R12.2, C13.2, C14.2, C15.2, C9.2, C10.2, C11.2, C12.2, Q1.2, R5.2, C5.2, Q2.2, R6.2, C6.2, Q3.2, R7.2, C7.2, Q4.2, R8.2, C8.2
- **IMU_INT**: U1.40, U2.INT
- **IMU_SCL**: U1.42, U2.SCL, R10.2
- **IMU_SDA**: U1.41, U2.SDA, R9.2
- **MOTOR1_NEG**: Q1.3, D1.2, J2.2, C1.2
- **MOTOR2_NEG**: Q2.3, D2.2, J3.2, C2.2
- **MOTOR3_NEG**: Q3.3, D3.2, J4.2, C3.2
- **MOTOR4_NEG**: Q4.3, D4.2, J5.2, C4.2
- **PWM1**: U1.14, R1.1
- **PWM2**: U1.21, R2.1
- **PWM3**: U1.47, R3.1
- **PWM4**: U1.39, R4.1
- **VBAT**: U3.VIN, J1.1, R11.1, C9.1, C10.1, D1.1, J2.1, C1.1, C5.1, D2.1, J3.1, C2.1, C6.1, D3.1, J4.1, C3.1, C7.1, D4.1, J5.1, C4.1, C8.1
- **VBAT_SENSE**: U1.1, R11.2, R12.1, C13.1
